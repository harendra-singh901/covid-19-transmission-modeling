# COVID-19 SEIR Model

A compartmental model of COVID-19 spread, comparing the simple SIR model
to the more realistic SEIR model (which adds an incubation period), and
fitting the model to case data.

## What this project does

1. **Model the disease spread** using both SIR and SEIR compartmental models
2. **Fit the model to case data** to estimate the infection rate (beta) and
   recovery rate (gamma)
3. **Sensitivity analysis** to see which parameters have the biggest effect
   on the size of the outbreak

## Project structure

```
src/
  seir_model.py   - the SIR and SEIR model equations and solvers
  fitting.py      - fitting beta/gamma to case data with curve_fit
  sensitivity.py  - one-at-a-time sensitivity analysis
  main.py         - runs everything and saves the plots
tests/
  test_seir_model.py
figures/          - output plots (generated by main.py)
```

## How to run it

```
pip install -r requirements.txt
cd src
python main.py
pytest ../tests
```

## The model

The SEIR model splits the population into four groups:
- **S**usceptible: haven't caught it yet
- **E**xposed: infected but not yet infectious (incubating)
- **I**nfected: infectious and can spread it to others
- **R**ecovered: recovered (or otherwise no longer infectious)

```
dS/dt = -beta * S * I / N
dE/dt =  beta * S * I / N - sigma * E
dI/dt =  sigma * E - gamma * I
dR/dt =  gamma * I
```

- `beta` = infection rate
- `sigma` = rate exposed people become infectious (1/sigma = incubation period)
- `gamma` = recovery rate (1/gamma = infectious period)
- `R0 = beta / gamma` = basic reproduction number (how many people one
  infected person infects on average, in a fully susceptible population)

The SIR model is the same thing but without the E compartment (assumes
people are infectious the moment they catch it).

## Results

Using beta=0.4, sigma=1/5.2 (~5.2 day incubation, a commonly cited early
COVID estimate), gamma=1/10 (~10 day infectious period), so R0 = 4.0:

- The SIR model peaks much earlier (around day 50) and higher than SEIR
  (around day 106). This makes sense: the incubation period in SEIR delays
  people becoming infectious, which spreads the outbreak out over more time.

- Fitting the model to 120 days of synthetic case data recovered beta and
  gamma reasonably close to the true values, and the fitted curve visually
  matches the data well. However the individual beta and gamma estimates
  were a bit further from the true values than I expected given their
  reported standard errors. My guess is that beta and gamma are somewhat
  correlated in this model (lots of different beta/gamma combinations can
  produce similar-looking growth curves early on), so cumulative case counts
  alone don't pin down each parameter that precisely on their own, even
  though R0 (their ratio) is estimated more reliably. I didn't have time to
  dig further into this, but it's a caveat worth flagging when reading the
  fitted numbers.

- The sensitivity analysis (varying each parameter +/-20%) shows gamma has
  the biggest effect on peak infections, followed by beta, then sigma. This
  makes intuitive sense: gamma controls how quickly people leave the
  infectious pool, which directly caps how many people can be infectious at
  once.

## Limitations / things I'd do differently with more time

- The case data used for fitting is synthetic (generated by the model
  itself, with noise added), not real reported case data, since I wanted to
  test the fitting code against a known answer first.
- Only beta and gamma are fitted; sigma is fixed from a published estimate,
  because fitting all three at once didn't converge reliably.
- The model assumes everyone mixes randomly (no age groups, no geography).
- No confidence intervals from the fit beyond the standard errors curve_fit
  reports — a more rigorous approach would use something like bootstrapping.
- The sensitivity analysis only varies one parameter at a time. A more
  thorough approach would vary all parameters together, but that seemed
  like more machinery than this project needed.
